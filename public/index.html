    Источники и методология

    Качество воздуха

    Open‑Meteo предоставляет оценки Copernicus CAMS для расчетных точек районов и Уральска. Пространственное разрешение глобальной модели — около 45 км. Европейский AQI основан на наибольшем из индексов отдельных загрязнителей. PM2.5, PM10 и NO₂ отображаются в мкг/м³. Цветовые интервалы этих слоёв служат для сравнения концентраций.

    Open‑Meteo / Copernicus CAMS

    Погода и карта

    Температура и ветер поступают из Open‑Meteo. Государственные границы, реки и озёра взяты из Natural Earth. Границы районов получены из открытого набора на основе OpenStreetMap (ODbL). Каждая точка характеризует выбранные координаты внутри района. Слой рек и озёр показывает расположение водоёмов.

    Open‑Meteo Weather API Скачать границы районов · OpenStreetMap / ODbL Условия OpenStreetMap / ODbL

    Состояние почвы

    Температура поверхности и объёмная влажность слоя 0–1 см поступают из Open‑Meteo. Значение 0,25 м³/м³ соответствует 25% воды по объёму. Цвета позволяют сравнивать точки. Для оценки химического загрязнения и плодородия нужны лабораторные данные.

    Обновление

    Сайт запрашивает данные при открытии, по кнопке «Обновить» и каждые 30 минут, пока вкладка видима. При сбое сохраняются последние доступные значения с исходным временем. Время отображается по UTC+5.

    Измерения на станциях

    Казгидромет публикует измерения на постах, а также карты качества поверхностных вод, почв и радиационного фона.

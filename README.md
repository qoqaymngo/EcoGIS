# ЭкоГИС — Западно-Казахстанская область

Веб-приложение для просмотра качества воздуха, состояния почвы и метеоусловий в 12 районах ЗКО и Уральске. Карта показывает границы районов и расчетную точку внутри каждой территории. Значения относятся к координатам точки. Границы кликабельны, район также можно выбрать из списка.

## Запуск в VS Code

1. Установите Node.js версии 22.9 или новее.
2. Распакуйте архив и откройте папку проекта в VS Code.
3. Выполните в терминале `npm start`.
4. Откройте [http://127.0.0.1:8000/](http://127.0.0.1:8000/).

Сторонние npm-пакеты для запуска не требуются. Для остановки используйте Ctrl+C. После изменения кода или настроек перезапустите сервер.

## Куда вставить API-ключ ИИ

В архиве есть файл `.env`. Вставьте ключ Gemini из Google AI Studio в строку `AI_API_KEY=`.

```dotenv
AI_API_KEY=ваш_ключ_Gemini
AI_PROVIDER=gemini
AI_MODEL=
```

Затем перезапустите `npm start`. Пустой `AI_MODEL` выбирает `gemini-3.8-flash`. Если вашему аккаунту доступна другая модель, впишите её точный идентификатор в `AI_MODEL`. Поддерживается также серверная переменная `GEMINI_API_KEY`.

Если файла `.env` нет, создайте его из `.env.example`. Ключ читает сервер, браузер вызывает `/api/chat` и `/api/analysis`. Для опубликованного сайта настройте серверный секрет `AI_API_KEY` и переменную `AI_PROVIDER=gemini`. Доступ к моделям и лимиты определяются вашим аккаунтом Google AI Studio.

В конфигурации остаются варианты `xai`, `groq` и `openai`, доступные через `AI_PROVIDER`.

## Возможности

- Карта границ районов ЗКО и территории Уральска, поиск и выбор района.
- Слои европейского AQI, PM2.5, PM10, NO₂, температуры воздуха и ветра.
- Слои температуры поверхности почвы и объёмной влажности 0–1 см.
- Почасовые графики за 24 и 48 часов.
- Локальный анализ тренда и отклонений, доступный без ключа.
- Текстовый ИИ-анализ и диалог с выбранной ИИ-моделью после настройки ключа.
- Таблица с сортировкой и фильтрами, экспорт текущих значений в CSV.

ИИ-чат получает название территории, текущие показатели и ряд выбранного слоя. Для анализа динамики другого показателя выберите нужный слой перед открытием чата. Переписка хранится в памяти вкладки. Данные отправляются выбранному провайдеру при запросе объяснения или отправке сообщения.

## Чат-бот из исходного проекта

Логика чата адаптирована из [web/chat.js](https://github.com/diarmadiev09-netizen/ecogis-zko/blob/main/web/chat.js), авторы исходного проекта — Қолқанат, Дияр, Аслан. Использован blob `9e133aa34e9d03ab9aab0e4aca998fa62600cabd`.

В новом `public/chat.js` реализован цикл до восьми запросов инструментов за один ответ. Помощник может перечислить территории, сравнить текущие показатели, запросить почасовой ряд, найти ближайшие расчетные точки и переключить район, слой и период графика. Инструменты читают текущие данные нашего проекта. Текст и действия отображаются в существующем окне чата.

Ключ ИИ задаётся в серверных настройках, запросы идут через `/api/chat`. Enter отправляет сообщение, Shift+Enter добавляет строку. Чат может отвечать на русском и казахском в зависимости от языка вопроса.

## Данные и ограничения охвата

Качество воздуха поступает из Open‑Meteo / Copernicus CAMS, погода и почвенные показатели — из Open‑Meteo Weather API. Влажность измеряется в м³/м³. Например, 0,25 соответствует 25% объёмной доли воды. Температура почвы относится к поверхности.

Почвенные слои характеризуют модельные влагу и температуру. Оценка тяжёлых металлов, pH, засоления и плодородия требует отдельных измерений. Расчетная точка представляет выбранные координаты внутри района. Локальные условия на других участках могут отличаться.

Границы районов основаны на OpenStreetMap и упрощены для веб-карты. Исходный региональный GeoJSON и ссылки на источник включены в проект. Реки и озёра основаны на Natural Earth.

Сайт обновляет данные при открытии, по кнопке и каждые 30 минут в видимой вкладке. В резервном `snapshot.json` сохранён полученный набор с исходными временными метками. При ошибке API он позволяет показать последние доступные значения.
